# Project Constitution

- Preserve Hermes session isolation, prompt-cache stability, and existing public behavior.
- Extend existing infrastructure before adding new surfaces or dependencies.
- Develop behavior changes test-first with focused integration coverage.
- Keep persistence backward compatible unless an approved specification requires a migration.
- Treat tests, lint, compilation, and clean diffs as independent completion evidence.
- Keep external delivery, installation, credentials, and destructive actions outside local implementation scope unless explicitly authorized.
